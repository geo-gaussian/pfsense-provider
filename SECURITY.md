# 🔒 Security Policy

## 📣 Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or discussions.
Use [GitHub private vulnerability reporting](https://github.com/geo-gaussian/terraform-provider-pfsense-nexus/security/advisories/new)
to contact the maintainers privately.

Include the affected provider version, a description of the issue, and
reproduction steps where possible. Do not include credentials, private keys,
tokens, Terraform state, or other sensitive configuration.

## 🛠️ Supported versions

This provider is experimental. Use the latest published version when
investigating an issue and include the version or commit in your report.
There is no established security support schedule yet.
